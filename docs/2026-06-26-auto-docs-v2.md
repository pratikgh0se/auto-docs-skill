# Auto-Docs v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade auto-docs skill to capture all meaningful work automatically via Stop hook + commit gate, with parallel haiku agents writing to `docs/`, a new WORKLOG.md for resume-oriented tracking, and MR description injection for code reviewers.

**Architecture:** A Stop hook detects work activity per turn and prompts the user to document; on confirmation it fans out parallel haiku agents (one per doc). A git `prepare-commit-msg` hook updates CHANGELOG.md and injects an AI Review Context block into open MRs. The skill itself is rewritten to orchestrate all of this and bootstrap new projects.

**Tech Stack:** Bash (hooks), Claude Code Workflows (parallel agents), `rtk` (all git/shell commands), `jq` (JSON parsing), GitLab API (MR updates), `claude-haiku-4-5-20251001` (all doc agents)

## Global Constraints

- All doc agents: `model: "global.anthropic.claude-haiku-4-5-20251001-v1:0"` hardcoded
- All shell commands inside agents: use `rtk` prefix (e.g. `rtk git log`)
- All agents: caveman ultra system prompt for internal reasoning
- All docs: live in `docs/` at project root, never project root itself
- `docs/WORKLOG.md`: always in `.gitignore`, never committed
- Toggle: skip all actions if `.claude/no-docs` exists in project root
- Never overwrite `.claude/settings.json` — always merge/append
- Never overwrite `CLAUDE.md` — always append (dedup-safe)
- Skill lives at: `~/.claude/skills/auto-docs/SKILL.md`
- Stop hook entry lives in: `~/.claude/settings.json` (global)

## The Five Documents

All docs live in `docs/` at project root.

| File | Trigger | Mode |
|------|---------|------|
| `docs/CHANGELOG.md` | Commit gate | Auto |
| `docs/ARCHITECTURE.md` | Structural change | Auto (ask first time) |
| `docs/USAGE.md` | Interface change | Auto (ask first time) |
| `docs/DECISIONS.md` | Significant decision | Ask every time |
| `docs/WORKLOG.md` | Stop hook, MR close | Auto (session) + prompted (feature) |

`docs/WORKLOG.md` is always added to `.gitignore`. Never commit it.

### docs/CHANGELOG.md

## [Unreleased]

### Added
- Payment webhook — chose idempotency key over dedup table for simpler rollback

### Changed
- Auth module — removed session token storage (compliance)

Write before commit. Stage with other files. One line per logical change, include WHY for non-obvious choices.

## Stop Hook Workflow

The Stop hook fires after every Claude turn. Auto-docs is invoked by the hook script when work is detected.

```
1. Check .claude/no-docs → skip if present
2. Detect work: files_changed OR bash_ran OR agents_ran?
3. No work detected → skip silently (pure Q&A)
4. Work detected → AskUserQuestion: "Document this work?"
5. No → skip
6. Yes → fan out parallel haiku agents (see Agent Architecture)
7. Check MR state: MR closed since last feature entry? → "Feature complete? Add feature summary?"
```

---

## Commit Gate Workflow

Runs via `prepare-commit-msg` git hook in the project repo.

```
1. Check .claude/no-docs → skip if present
2. Check trivial commit → skip all docs if so
3. Update docs/CHANGELOG.md → stage it
4. Structural change? → update docs/ARCHITECTURE.md → stage it
5. Interface change? → update docs/USAGE.md → stage it
6. On feature branch with open MR? → update MR description (AI Review Context block)
```

---

## Agent Architecture

Parallel haiku agents, one per doc:

```
User confirms "Document this work?"
  → Workflow (haiku, caveman ultra)
    ├── Agent A: docs/CHANGELOG.md  (if commits present)
    ├── Agent B: docs/ARCHITECTURE.md  (if structural change)
    ├── Agent C: docs/USAGE.md  (if interface change)
    ├── Agent D: docs/DECISIONS.md  (only if decision confirmed this session)
    └── Agent E: docs/WORKLOG.md  (always — session entry)
```

Each agent:
- `model: "global.anthropic.claude-haiku-4-5-20251001-v1:0"`
- Caveman ultra system prompt
- Uses `rtk` for all shell/git commands
- Reads existing doc first, appends/updates — never full rewrite
- Writes only its assigned file

---

## MR Description Format

Commit gate appends once, updates on subsequent commits (never duplicates the block):

```markdown
---
## AI Review Context

**Changes in this MR:**
- Bullet per logical change

**Key decisions & tradeoffs:**
- Decision: chose X over Y because Z

**Known limitations / follow-ups:**
- ...

**Full context:** `docs/ARCHITECTURE.md`, `docs/DECISIONS.md`
```

Sourced from `docs/DECISIONS.md` entries since branch creation. Omits sections with no data. Only runs on feature branches with open MR — skips `main`/`master`.

- [ ] **Step 3: Write the stop hook script**

```bash
cat > ~/.claude/hooks/auto-docs-stop.sh << 'HOOKEOF'
#!/usr/bin/env bash
# Auto-docs Stop hook — detects work, prompts user to document

set -euo pipefail

# Read stdin (Stop hook passes JSON)
INPUT=$(cat)

# Parse turn metadata
WORKING_DIR=$(echo "$INPUT" | jq -r '.workingDir // empty' 2>/dev/null || pwd)
TOOL_USE_COUNT=$(echo "$INPUT" | jq -r '.toolUseCount // 0' 2>/dev/null || echo 0)

# Skip if toggle present
if [ -f "$WORKING_DIR/.claude/no-docs" ]; then
  exit 0
fi

# Skip if not a git repo
if ! git -C "$WORKING_DIR" rev-parse --git-dir > /dev/null 2>&1; then
  exit 0
fi

# Detect work: bash ran, agents ran, or files changed
FILES_CHANGED=$(git -C "$WORKING_DIR" diff --name-only HEAD 2>/dev/null | wc -l | tr -d ' ')
STAGED_FILES=$(git -C "$WORKING_DIR" diff --cached --name-only 2>/dev/null | wc -l | tr -d ' ')

TOTAL_CHANGED=$((FILES_CHANGED + STAGED_FILES))

# If tool_use_count > 0 or files changed, work was done
if [ "$TOOL_USE_COUNT" -gt 0 ] || [ "$TOTAL_CHANGED" -gt 0 ]; then
  # Signal to Claude Code to invoke auto-docs skill
  # Claude Code Stop hooks can emit a prompt back to the model
  echo '{"decision": "invoke_auto_docs", "workingDir": "'"$WORKING_DIR"'", "filesChanged": '"$TOTAL_CHANGED"', "toolUseCount": '"$TOOL_USE_COUNT"'}'
fi

exit 0
HOOKEOF
chmod +x ~/.claude/hooks/auto-docs-stop.sh
```

### Task 4: Write prepare-commit-msg Hook Script

Git hook that fires at commit time. Updates CHANGELOG.md and MR description.

**Files:**
- Create: `~/.claude/hooks/auto-docs-prepare-commit-msg.sh`
- Note: This script is installed into individual projects by the auto-docs skill bootstrap, not globally.

**Interfaces:**
- Consumes: `$1` = commit msg file, `$2` = commit source (message/template/merge/squash)
- Produces: updated `docs/CHANGELOG.md` staged, MR description updated if on feature branch

- [ ] **Step 1: Write the hook script**

```bash
cat > ~/.claude/hooks/auto-docs-prepare-commit-msg.sh << 'HOOKEOF'
#!/usr/bin/env bash
# Auto-docs prepare-commit-msg hook
# Updates docs/CHANGELOG.md and MR description

set -euo pipefail

COMMIT_MSG_FILE="$1"
COMMIT_SOURCE="${2:-}"

# Skip merge commits, squash commits, amends
if [ "$COMMIT_SOURCE" = "merge" ] || [ "$COMMIT_SOURCE" = "squash" ]; then
  exit 0
fi

# Skip if toggle present
if [ -f ".claude/no-docs" ]; then
  exit 0
fi

# Skip if docs/ doesn't exist yet
if [ ! -d "docs" ]; then
  exit 0
fi

COMMIT_MSG=$(cat "$COMMIT_MSG_FILE")

# Skip trivial commits (WIP, fixup, typo, fmt)
if echo "$COMMIT_MSG" | grep -qiE '^(wip|fixup|squash|typo|fmt|format|whitespace)'; then
  exit 0
fi

BRANCH=$(rtk git rev-parse --abbrev-ref HEAD 2>/dev/null || echo "")
DIFF=$(rtk git diff --cached --stat 2>/dev/null || echo "")
DATE=$(date +%Y-%m-%d)

# Update CHANGELOG.md
if [ ! -f "docs/CHANGELOG.md" ]; then
  cat > docs/CHANGELOG.md << 'EOF'
# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]
EOF
fi

# Append changelog entry under [Unreleased]
# Extract type from conventional commit prefix if present
TYPE="Changed"
if echo "$COMMIT_MSG" | grep -q '^feat'; then TYPE="Added"; fi
if echo "$COMMIT_MSG" | grep -q '^fix'; then TYPE="Fixed"; fi
if echo "$COMMIT_MSG" | grep -q '^remove\|^delete'; then TYPE="Removed"; fi

# Insert under [Unreleased] section
ENTRY="- $COMMIT_MSG"
sed -i.bak "/^## \[Unreleased\]/a\\\\n### $TYPE\\n$ENTRY" docs/CHANGELOG.md 2>/dev/null || true
rm -f docs/CHANGELOG.md.bak

rtk git add docs/CHANGELOG.md

# Update MR description if on feature branch with open MR
if [ -n "$BRANCH" ] && [ "$BRANCH" != "main" ] && [ "$BRANCH" != "master" ]; then
  # Check if GitLab remote
  REMOTE_URL=$(rtk git remote get-url origin 2>/dev/null || echo "")
  if echo "$REMOTE_URL" | grep -q "gitlab"; then
    # Extract project path from remote URL
    PROJECT_PATH=$(echo "$REMOTE_URL" | sed 's|.*gitlab[^/]*/||' | sed 's|\.git$||')
    GITLAB_HOST=$(echo "$REMOTE_URL" | sed 's|.*@||' | sed 's|:.*||' | sed 's|/.*||')

    # Find open MR for this branch
    if [ -n "${GITLAB_TOKEN:-}" ]; then
      MR_IID=$(curl -sf \
        -H "PRIVATE-TOKEN: $GITLAB_TOKEN" \
        "https://$GITLAB_HOST/api/v4/projects/$(python3 -c "import urllib.parse,sys; print(urllib.parse.quote(sys.argv[1], safe=''))" "$PROJECT_PATH")/merge_requests?source_branch=$BRANCH&state=opened" \
        2>/dev/null | jq -r '.[0].iid // empty' 2>/dev/null || echo "")

      if [ -n "$MR_IID" ]; then
        # Build decisions block from docs/DECISIONS.md entries since branch was created
        DECISIONS_BLOCK=""
        if [ -f "docs/DECISIONS.md" ]; then
          DECISIONS_BLOCK=$(grep -A3 "^\## \[" docs/DECISIONS.md | head -20 || echo "")
        fi

        AI_CONTEXT="---\n## AI Review Context\n\n**Changes in this MR:**\n$(rtk git log origin/main..HEAD --oneline 2>/dev/null | sed 's/^/- /' | head -10)\n\n**Full context:** \`docs/ARCHITECTURE.md\`, \`docs/DECISIONS.md\`"

        if [ -n "$DECISIONS_BLOCK" ]; then
          AI_CONTEXT="$AI_CONTEXT\n\n**Key decisions \& tradeoffs:**\n$(echo "$DECISIONS_BLOCK" | head -10 | sed 's/^/- /')"
        fi

        # Update MR description via API
        CURRENT_DESC=$(curl -sf \
          -H "PRIVATE-TOKEN: $GITLAB_TOKEN" \
          "https://$GITLAB_HOST/api/v4/projects/$(python3 -c "import urllib.parse,sys; print(urllib.parse.quote(sys.argv[1], safe=''))" "$PROJECT_PATH")/merge_requests/$MR_IID" \
          2>/dev/null | jq -r '.description // ""' 2>/dev/null || echo "")

        # Remove existing AI Review Context block if present, then append updated one
        NEW_DESC=$(echo "$CURRENT_DESC" | sed '/^---$/,/^## AI Review Context/,/^\*\*Full context\*\*/{ /^## AI Review Context/,/^\*\*Full context\*\*.*$/d }' 2>/dev/null || echo "$CURRENT_DESC")
        NEW_DESC="$NEW_DESC\n\n$AI_CONTEXT"

        curl -sf -X PUT \
          -H "PRIVATE-TOKEN: $GITLAB_TOKEN" \
          -H "Content-Type: application/json" \
          -d "{\"description\": $(echo "$NEW_DESC" | jq -Rs .)}" \
          "https://$GITLAB_HOST/api/v4/projects/$(python3 -c "import urllib.parse,sys; print(urllib.parse.quote(sys.argv[1], safe=''))" "$PROJECT_PATH")/merge_requests/$MR_IID" \
          > /dev/null 2>&1 || true
      fi
    fi
  fi
fi

exit 0
HOOKEOF
chmod +x ~/.claude/hooks/auto-docs-prepare-commit-msg.sh
```

**Files:**
- Create: `~/.claude/workflows/auto-docs.js`

**Interfaces:**
- Consumes: `args = { workingDir, filesChanged, toolUseCount, sessionSummary }`
- Produces: updated doc files in `args.workingDir/docs/`

- [ ] **Step 1: Create workflows directory**

```bash

```

- [ ] **Step 2: Write workflow**

```javascript
// ~/.claude/workflows/auto-docs.js
export const meta = {
  name: 'auto-docs',
  description: 'Fan out haiku agents to update project docs after work session',
  phases: [
    { title: 'Detect', detail: 'Determine which docs need updating' },
    { title: 'Write', detail: 'Parallel haiku agents write each doc' },
  ],
}

const HAIKU = 'global.anthropic.claude-haiku-4-5-20251001-v1:0'

const CAVEMAN_ULTRA = `
CAVEMAN MODE ULTRA. Maximum compression. No articles, no filler, no pleasantries.
Fragments OK. Technical terms exact. Code blocks unchanged.
`.trim()

const workingDir = args?.workingDir || '.'

phase('Detect')

const context = await agent(
  `You are detecting which docs need updating after a work session.
Working dir: ${workingDir}

Run these commands and report results as JSON:
- rtk git diff --name-only HEAD (files changed)
- rtk git diff --cached --name-only (staged files)  
- rtk git log --oneline -10 (recent commits)
- cat ${workingDir}/docs/DECISIONS.md 2>/dev/null | tail -20 (recent decisions)
- rtk git branch --show-current (current branch)

Return JSON: { filesChanged: string[], stagedFiles: string[], recentCommits: string[], hasPendingDecisions: boolean, currentBranch: string }`,
  {
    label: 'detect:context',
    phase: 'Detect',
    model: HAIKU,
    schema: {
      type: 'object',
      properties: {
        filesChanged: { type: 'array', items: { type: 'string' } },
        stagedFiles: { type: 'array', items: { type: 'string' } },
        recentCommits: { type: 'array', items: { type: 'string' } },
        hasPendingDecisions: { type: 'boolean' },
        currentBranch: { type: 'string' },
      },
      required: ['filesChanged', 'stagedFiles', 'recentCommits', 'hasPendingDecisions', 'currentBranch'],
    },
  }
)

// Determine which docs need updating
const hasCommits = context.recentCommits.length > 0
const hasStructuralChange = context.filesChanged.some(f =>
  f.match(/\.(go|py|ts|js|java|rs|rb|cs)$/) && !f.includes('test')
)
const hasInterfaceChange = context.filesChanged.some(f =>
  f.match(/(api|route|endpoint|cli|cmd|handler)/i)
)

log(`Files changed: ${context.filesChanged.length}, structural: ${hasStructuralChange}, interface: ${hasInterfaceChange}`)

phase('Write')

const agents = []

// WORKLOG.md — always
agents.push(() => agent(
  `${CAVEMAN_ULTRA}

Update ${workingDir}/docs/WORKLOG.md with session entry for today.

Context:
- Files changed: ${context.filesChanged.join(', ') || 'none'}
- Recent commits: ${context.recentCommits.join('; ') || 'none'}
- Branch: ${context.currentBranch}
- Session summary from user: ${args?.sessionSummary || 'not provided'}

Steps:
1. Read ${workingDir}/docs/WORKLOG.md (create if missing)
2. Append new session entry at top (under any existing entries):

## Session: ${new Date().toISOString().split('T')[0]}

**What I worked on:** [infer from commits/files]
**Challenges:** [infer from commit messages, file names]
**Outcome:** [current state of work]

3. Write updated file to ${workingDir}/docs/WORKLOG.md
4. DO NOT commit this file`,
  { label: 'write:worklog', phase: 'Write', model: HAIKU }
))

// CHANGELOG.md — if commits
if (hasCommits) {
  agents.push(() => agent(
    `${CAVEMAN_ULTRA}

Update ${workingDir}/docs/CHANGELOG.md with entries for recent work.

Recent commits: ${context.recentCommits.join('\n')}
Files changed: ${context.filesChanged.join(', ')}

Steps:
1. Read ${workingDir}/docs/CHANGELOG.md (create with keep-a-changelog header if missing)
2. Add entries under [Unreleased] section — one line per logical change, include WHY for non-obvious
3. Categorize as Added/Changed/Fixed/Removed
4. Stage the file: rtk git add ${workingDir}/docs/CHANGELOG.md`,
    { label: 'write:changelog', phase: 'Write', model: HAIKU }
  ))
}

// ARCHITECTURE.md — if structural change
if (hasStructuralChange) {
  agents.push(() => agent(
    `${CAVEMAN_ULTRA}

Update ${workingDir}/docs/ARCHITECTURE.md to reflect structural changes.

Files changed: ${context.filesChanged.join(', ')}

Steps:
1. Read ${workingDir}/docs/ARCHITECTURE.md
2. If missing: scan project structure first (rtk git ls-files | head -50), then write from scratch
3. If exists: update ONLY the section(s) affected by changed files
4. Sections: What This Is, System Overview, Key Design Principles, Data Model, External Dependencies, Known Constraints
5. Write updated file`,
    { label: 'write:architecture', phase: 'Write', model: HAIKU }
  ))
}

// USAGE.md — if interface change  
if (hasInterfaceChange) {
  agents.push(() => agent(
    `${CAVEMAN_ULTRA}

Update ${workingDir}/docs/USAGE.md to reflect interface changes.

Files changed: ${context.filesChanged.filter(f => f.match(/(api|route|endpoint|cli|cmd|handler)/i)).join(', ')}

Steps:
1. Read ${workingDir}/docs/USAGE.md
2. If missing: scan project for CLI/API surface, write from scratch
3. If exists: update ONLY the section(s) touched by changes
4. Write updated file`,
    { label: 'write:usage', phase: 'Write', model: HAIKU }
  ))
}

// DECISIONS.md — only if pending decisions
if (context.hasPendingDecisions) {
  agents.push(() => agent(
    `${CAVEMAN_ULTRA}

Append decision entry to ${workingDir}/docs/DECISIONS.md.

Context: Recent work on ${context.currentBranch}, files: ${context.filesChanged.join(', ')}

Steps:
1. Read ${workingDir}/docs/DECISIONS.md
2. Identify the most significant architectural/design decision from this session
3. Append entry:

## [${new Date().toISOString().split('T')[0]}] [Decision Title]

**Context:** [what prompted this]
**Decision:** [what was chosen and why]
**Alternatives considered:** [what else, why rejected]
**Consequences:** [what this shapes going forward]

4. Write updated file`,
    { label: 'write:decisions', phase: 'Write', model: HAIKU }
  ))
}

// Fan out all agents in parallel
const results = await parallel(agents)

log(`Completed: ${results.filter(Boolean).length}/${agents.length} doc agents succeeded`)

return { docsUpdated: results.filter(Boolean).length }
```
